# Fotografias da oficina

As imagens públicas do site ficam em `public/assets/images/`. As fotografias do equipamento Corghi são utilizadas na seção de tecnologia e equipamentos.

Para adicionar ou trocar fotos pelo painel, entre com a senha administrativa definida na variável `ADMIN_PASSWORD` do servidor. Nenhuma senha deve ser incluída neste documento ou no código do navegador.

O gerenciamento de fotos ainda usa arquivos locais do servidor. Esta integração com Supabase migra apenas a agenda; armazenamento persistente de imagens deverá ser configurado separadamente.
